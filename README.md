 C++ Operator Overloading for Input and Output

This project demonstrates **operator overloading in C++** by overloading the `<<` and `>>` operators for a user-defined class.

 🔹 Features

* Uses a custom `op` class to store a user's name.
* Overloads the **insertion operator (`<<`)** to display the name.
* Overloads the **extraction operator (`>>`)** to accept the name as input.
* Uses **friend functions** to access the private/class data members.
* Demonstrates how C++ operators can be customized for user-defined objects.

 🛠️ Concepts Used

* C++
* Classes and Objects
* Friend Functions
* Operator Overloading
* Input/Output Streams
* `cin` and `cout`

▶️ Example

🎯 Purpose

The purpose of this project is to understand how **operator overloading works in C++** and how standard operators such as `>>` and `<<` can be used with custom classes.
